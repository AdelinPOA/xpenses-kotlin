# Expenses Components

## Overview
Expense creation/editing forms, FX rate override input, bulk receipt upload and inline row review, immediate OCR review with conflict/idempotency handling, receipt capture/preview/lightbox viewers, authenticated image rendering, and offline queue status controls.

## Interface
- `[AuthorizedImage.tsx:AuthorizedImage]` — Default-exported client component accepting `AuthorizedImageProps`: `{ src: string; alt?: string } & Omit<React.ImgHTMLAttributes<HTMLImageElement>, "src">` (`alt` defaults to `""`).
- `[BulkReviewDrawer.tsx:BulkReviewDrawer]` — Default-exported client component accepting `BulkReviewDrawerProps`: `{ files: File[]; isOpen: boolean; onClose: () => void }`.
- `[BulkUploadZone.tsx:filterFiles]` — Exported function `(raw: FileList | File[]) => { valid: File[]; rejected: { name: string; reason: "type" | "size" | "count" | "total" }[] }`.
- `[BulkUploadZone.tsx:BulkUploadZone]` — Default-exported client component accepting `BulkUploadZoneProps`: `{ isDragging: boolean; onFilesDropped: (files: File[]) => void }`.
- `[ExpenseForm.tsx:ExpenseForm]` — Default-exported client component accepting `Props`: `{ expense?: Expense; reportId?: number; defaultCurrency?: string; highlightReceipts?: boolean; returnToReportId?: number }`.
- `[ExpenseForm.tsx:Props]` — Internal component props interface `{ expense?: Expense; reportId?: number; defaultCurrency?: string; highlightReceipts?: boolean; returnToReportId?: number }`.
- `[FxRateInput.tsx:FxRateInput]` — Default-exported client component accepting `Props`: `{ active: boolean; currency: string; amount: string; date: string; initialRate?: number | null; initialManualRate?: number | null; initialEditorRate?: number | null; onToggle: () => void; onManualRateChange: (rate: number | null) => void }`.
- `[FxRateInput.tsx:Props]` — Internal component props interface for `FxRateInput`.
- `[ImmediateExpenseReview.tsx:ImmediateExpenseReview]` — Default-exported client component accepting `{ expense: Expense; sourceId?: string | null; recoveringConfirmedOperation?: boolean; onSourceUnavailableAction?: () => void; onReloadAction: () => Promise<Expense | null> }`.
- `[OfflineQueuePanel.tsx:OfflineQueuePanel]` — Default-exported client component accepting `{ onClose: () => void }`.
- `[ReceiptLightbox.tsx:ReceiptLightbox]` — Default-exported client component accepting `Props`: `{ isOpen: boolean; onClose: () => void; imageUrl: string; title?: string; onDownload?: () => void }`.
- `[ReceiptPreview.tsx:ReceiptPreview]` — Default-exported client component accepting `Props`: `{ items: ReceiptItem[]; activeItem: ReceiptItem | null; zoom: number; position: { x: number; y: number }; isDraggingImage: boolean; activeReceiptKey: string | null; onSelectItem: (key: string) => void; onZoomIn: () => void; onZoomOut: () => void; onReset: () => void; onPointerDown: (e: React.PointerEvent<HTMLDivElement>) => void; onPointerMove: (e: React.PointerEvent<HTMLDivElement>) => void; onPointerUp: () => void; sanitizeUrl: (url: string) => string }` (file-local `ReceiptItem`: `{ key: string; name: string; url: string; isImage: boolean; isPdf: boolean }`).
- `[ReceiptScanner.tsx:ReceiptScanner]` — Default-exported client component accepting `Props`: `{ isScanning: boolean; scanProgress?: ScanProgress | null; onCancelScan?: () => void; isDragging: boolean; onScan: (e: React.ChangeEvent<HTMLInputElement>) => void; onCameraCapture: (e: React.ChangeEvent<HTMLInputElement>) => void; onDragOver: (e: React.DragEvent) => void; onDragLeave: (e: React.DragEvent) => void; onDrop: (e: React.DragEvent) => void; onClick: () => void; scanInputRef: React.RefObject<HTMLInputElement | null>; cameraInputRef: React.RefObject<HTMLInputElement | null> }`.

## Invariants
- `[AuthorizedImage.tsx:AuthorizedImage]` Authenticated blob fetch (`needsAuthFetch`) runs only when `src` starts with `${API_BASE_URL}/` or `/api/`, stripping `API_BASE_URL` or leading `/api` to build `requestPath`.
- `[AuthorizedImage.tsx:AuthorizedImage]` Renders `null` while `objectUrl` is `null` or `failed` is `true`, and ignores async resolution/rejection after cleanup sets `cancelled = true`.
- `[BulkReviewDrawer.tsx:BulkReviewDrawer]` Renders `null` when `!isOpen`.
- `[BulkReviewDrawer.tsx:BulkReviewDrawer]` Generates one `crypto.randomUUID()` `batchKey` per open upload batch and sends `Idempotency-Key` headers on bulk upload (`batchKey`) and receipt retry (`${batchKey}:receipt:${file_index}`); never automatically retries an ambiguous batch upload.
- `[BulkReviewDrawer.tsx:BulkReviewDrawer]` Never matches legacy upload errors lacking `expense_id` to an `Expense` by filename; receipt retry requires `!receiptRetryRef.current && error.expense_id != null && error.file_index != null && files[error.file_index]`.
- `[BulkReviewDrawer.tsx:saveRow]` Serializes concurrent saves per expense ID via `requested` and `running` `Set<number>` refs; skips `PATCH` and sets `row.error = true` if `amount` is blank/non-finite/`< 0`, `currency` fails `/^[A-Z]{3}$/`, or `date` is empty.
- `[BulkReviewDrawer.tsx:patchOf]` Converts `amount` and `category_id` to `Number(value)` and emits `{ clear_category: true }` instead of `category_id` when `category_id` is empty.
- `[BulkReviewDrawer.tsx:acknowledged]` Verifies field-level acknowledgement from the `PATCH` response (`Number(sent) === Number(received)` for `amount`, strict equality for other fields), keeps unacknowledged/failed fields in `row.uncertain` for subsequent `fieldsToSave` calls, and preserves newer concurrent user edits.
- `[BulkReviewDrawer.tsx:deleteRow]` Ignores delete requests while `row.saving` or `row.deleting` is `true`.
- `[BulkReviewDrawer.tsx:handleClose]` Sets `closeBlocked = true` and aborts close if `uploadingRef.current`, `receiptRetryRef.current`, or any non-deleted row is unfinished (`dirty`, `error`, `uncertain.length > 0`, `saving`, or `deleting`); requires `window.confirm` if any `uploadErrors` carry `expense_id != null`.
- `[BulkReviewDrawer.tsx:BulkExpenseRow]` Marks a row as needing review when `!Number(values.amount) || Number(values.amount) <= 0`, uppercases `currency` with `maxLength={3}`, and renders receipt thumbnails via `<img src="/api/expenses/${expense.id}/receipts/${expense.receipts[0].id}">` when `expense.receipts[0]` exists.
- `[BulkUploadZone.tsx:filterFiles]` Rejects the entire batch with reason `"count"` if `files.length > 20`; per file requires extension matching `/\.(jpe?g|png|webp|pdf)$/i`, MIME type (when non-empty) in `["image/jpeg", "image/png", "image/webp", "application/pdf"]` (`"type"`), and `file.size <= 10 * 1024 * 1024` (`"size"`); rejects all valid files with reason `"total"` if valid byte sum exceeds `MAX_BATCH_BYTES` (9 MiB) or bytes plus estimated multipart `metadataBytes` exceeds `MAX_REQUEST_BYTES` (10 MiB).
- `[BulkUploadZone.tsx:BulkUploadZone]` Invokes `onFilesDropped(result.valid)` only when `result.valid.length > 0` and clears `e.target.value` after selection.
- `[ExpenseForm.tsx:ExpenseForm]` `isEdit` is `!!expense`; editing requires `navigator.onLine` (throwing `edit_offline_unsupported` when offline) and never creates a replacement `Expense` if receipt deletion or upload fails.
- `[ExpenseForm.tsx:ExpenseForm]` Creating a new expense requires `user?.id` (throwing `error_save` if missing); `report_id` is included in the save payload only when `reportId` is truthy and `!currentExpense?.report_id`; `returnToReportId` only governs post-save navigation/refresh.
- `[ExpenseForm.tsx:ExpenseForm]` `FxRateInput` renders only when `form.currency !== "EUR"`, and `fx_rate` / `fx_rate_manual` are sent only when `fxRateEditMode` is `true` and `manualFxRate !== null`.
- `[ExpenseForm.tsx:ExpenseForm]` Deleting existing receipts ignores HTTP 404 responses; any other receipt delete/upload error aborts remaining receipt operations and sets `receiptUploadFailed: true`. When creating a new expense yields `outcome.status === "partial"`, navigates to `/expenses/${result.id}/edit?upload_failed=1` to avoid duplicate creation on retry; on edit receipt failure, stays on page with `receiptUploadFailedLocal = true`.
- `[ExpenseForm.tsx:ExpenseForm]` `isDirty` is `true` if any `FormFields` key differs from `initialFieldsRef`, `fxRateEditMode` or `manualFxRate` differs from `initialFxRef`, `receiptFiles.length > 0`, or `deletedReceiptIds.size > 0`; Cancel requires `!isDirty()` or `window.confirm` before `router.back()`.
- `[ExpenseForm.tsx:ExpenseForm]` Receipt preview zoom is clamped to `[0.5, 3]` in `0.25` increments, pointer dragging requires `zoom > 1`, and `zoom`/`position` reset whenever `activeReceiptKey` changes. Input constraints: `amount` (`required`, `min=0`, `step=0.01`), `date` (`required`), `tax_amount` (default `"0"`, `min=0`, `step=0.01`), `tax_rate` (`min=0`, `step=0.01`), and receipts file input (`multiple`, `accept=".jpg,.jpeg,.png,.pdf,.webp"`).
- `[ExpenseForm.tsx:sanitizeUrl]` Rejects `javascript:`, `data:`, `file:`, and `vbscript:` protocols (returning `""`), preserves `blob:` URLs verbatim, and returns `parsed.href` or `""` on invalid URLs.
- `[FxRateInput.tsx:FxRateInput]` `debitCurrencies` excludes `currency`; changing `currency` resets `debitTouched`, `debitAmount`, and `rateValue`, and resets `debitCurrency` to `"EUR"` if it matched the new `currency`. `rateValue` is seeded from `initialEditorRate ?? initialRate` only on the `false -> true` transition of `active`.
- `[FxRateInput.tsx:FxRateInput]` `prefillValue` is computed only when `initialManualRate` is truthy and `amountNum > 0`; `derived` returns `{ rate, eur }` only when `amountNum > 0` and either `mode === "rate"` with `rateNum > 0`, or `mode === "debit"` with `effectiveDebit > 0` (and quote loaded when `debitCurrency !== "EUR"`). `deviationWarning` is `true` only when `derived?.eur != null`, `autoEur != null`, and `Math.abs(derived.eur - autoEur) / autoEur > 0.25`. Numeric inputs enforce `debitAmount` (`min=0.01`, `step=0.01`) and `rateValue` (`min=0.0001`, `step=0.0001`).
- `[ImmediateExpenseReview.tsx:reviewBody]` Requires finite `amount > 0`, non-empty `date`, finite `taxAmount >= 0` (defaults to `0` when blank), optional finite `taxRate >= 0`, optional safe integer `categoryId > 0` (emitting `clear_category: true` when cleared from non-null), and numeric `expense.version` as `expected_version`. Includes `fx_rate` and `fx_rate_manual: true` only when `fxRateEditMode && manualFxRate !== null && (!expense.fx_rate_manual || manualFxRate !== expense.fx_rate)`.
- `[ImmediateExpenseReview.tsx:ImmediateExpenseReview]` Form fieldset is disabled when `submitting || source?.reviewSyncState === "uncertain" || source?.reviewSyncState === "conflict" || !sourceLoaded || expense.status !== "draft"`. `saveOrConfirm` aborts when `!online` or `source?.reviewSyncState === "conflict"`; confirm buttons require `online && !submitting && sourceLoaded && Boolean(expense.receipts?.length)`; reuses existing `source.reviewOperation` (and its idempotency key) when `sameBody(existing.body, body)` holds, otherwise generates a new UUID via `crypto.randomUUID()`.
- `[ImmediateExpenseReview.tsx:ImmediateExpenseReview]` If `operation.body.confirm` is `true` and response `Expense.verification_state !== "VERIFIED"`, transitions `reviewSyncState` to `"conflict"` instead of confirming. On mount/source load, an existing `record.reviewOperation` forces `reviewSyncState` to `"uncertain"`; mismatched `expenseVersion` with existing non-server-saved `reviewValues` forces `"conflict"`; otherwise mismatched `expenseVersion` updates `expenseVersion` and clears `reviewValues`.
- `[ImmediateExpenseReview.tsx:sanitizeUrl]` Permits only `blob:` URLs, `/`-prefixed relative paths, or `http:`/`https:` URLs, returning `""` otherwise; receipt preview pan requires `zoom > 1` and zoom buttons clamp zoom to `[0.5, 3]` in `0.25` steps.
- `[OfflineQueuePanel.tsx:OfflineQueuePanel]` Consumes `items`, `retryItem`, and `discardItem` from `useOfflineSync()`; renders empty-state notice when `items.length === 0`, renders edit `<Link>` only when `item.expenseId` is truthy, and displays `item.error` before stage-based pending text.
- `[ReceiptLightbox.tsx:ReceiptLightbox]` Returns `null` when `!isOpen`; clamps zoom to `[1, 4]` (`0.5` button step, `2x` double-click toggle, pinch delta `> 5px`), resets position to `{ x: 0, y: 0 }` at `zoom === 1`, and allows pointer dragging only when `zoom > 1`.
- `[ReceiptPreview.tsx:ReceiptPreview]` Renders multi-file tabs only when `items.length > 1` (defaulting active tab to `idx === 0` when `activeReceiptKey === null`), switches view by `activeItem.isImage` / `activeItem.isPdf` / fallback / empty state, and routes all link `href` and iframe `src` values through `sanitizeUrl`.
- `[ReceiptScanner.tsx:ReceiptScanner]` Restricts `#receipt-scan-input` to `accept=".jpg,.jpeg,.png,.pdf,.webp"` and `#receipt-camera-input` to `accept="image/*"` with `capture="environment"`; calls `event.preventDefault()` on dragover/drop and forwards them only when `!isScanning`; renders progress status with optional cancel button when `isScanning` is `true`.

## Side Effects
- `[AuthorizedImage.tsx:AuthorizedImage]` Fetches image bytes via `api.get<Blob>(requestPath, { responseType: "blob" })`, allocates a blob URL with `URL.createObjectURL`, and revokes it via `URL.revokeObjectURL` on cleanup.
- `[BulkReviewDrawer.tsx:BulkReviewDrawer]` Locks body scroll via `useBodyScrollLock(isOpen)`, queries `GET /categories` (`categoryKeys.list()`) when open, compresses files via `compressImage`/`compressedUploadName`, posts `FormData` to `POST /expenses/bulk-upload`, sends `PATCH /expenses/${id}`, `DELETE /expenses/${id}`, and `POST /expenses/${error.expense_id}/receipts`, invalidates `expenseKeys.all` in `queryClient`, attaches `keydown` (`Escape`) and `beforeunload` listeners, and calls `window.confirm` / `onClose()`.
- `[BulkUploadZone.tsx:BulkUploadZone]` Programmatically clicks hidden file input via `inputRef.current?.click()`, portals a full-screen drop overlay into `document.body` when `isDragging && typeof window !== "undefined"`, and invokes `onFilesDropped(result.valid)`.
- `[ExpenseForm.tsx:ExpenseForm]` Queries `GET /categories` (`categoryKeys.list()`, `staleTime: 300_000`, `gcTime: 600_000`), calls `PATCH /expenses/${currentExpense.id}`, `DELETE /expenses/${result.id}/receipts/${rid}`, `POST /expenses/${result.id}/receipts` or `saveNewExpense(...)`, invalidates `expenseKeys.all` / `dashboardKeys.all` / `reportKeys.all`, calls `refreshOffline()`, shows `toast.success`/`toast.warning`, optionally calls `qc.fetchQuery` / `qc.removeQueries` for `/reports/${returnToReportId}`, calls `clearDirty()`, navigates via `router.push` (with a `2000ms` `setTimeout` for non-EUR receipts), manages `URL.createObjectURL` / `URL.revokeObjectURL`, triggers receipt downloads via `downloadBlob`, registers `useFormGuard` / `window.confirm`, generates UUIDs via `crypto.randomUUID()`, and captures pointer events with `setPointerCapture`.
- `[FxRateInput.tsx:FxRateInput]` Queries `GET /fx/quote` for `debitCurrency` (when `active && mode === "debit" && debitCurrency !== "EUR"`) and `currency` (when `active`) with `staleTime: 300_000`, and invokes `onManualRateChange(derived ? derived.rate : null)` via `useEffect`.
- `[ImmediateExpenseReview.tsx:ImmediateExpenseReview]` Queries `GET /categories` (`categoryKeys.list()`), attaches `window` `online`/`offline` listeners, registers `useFormGuard`, reads/writes the local OCR queue (`listOcrSources`, `findOcrSourceByExpenseId`, `persistOcrReviewState` with 200ms debounced autosave, `removeOcrSource`), sends `PUT /expenses/${expense.id}/review` with `Idempotency-Key`, invalidates `expenseKeys.all` and `dashboardKeys.all`, shows `toast.success`, navigates via `router.push`, invokes `onSourceUnavailableAction` / `onReloadAction`, and captures pointer events with `setPointerCapture`.
- `[OfflineQueuePanel.tsx:OfflineQueuePanel]` Invokes `onClose()`, `retryItem(item.id)`, and `discardItem(item.id)` on button clicks.
- `[ReceiptLightbox.tsx:ReceiptLightbox]` Mutates `document.body.style.overflow` (`"hidden"` while open, `""` on close/unmount), attaches a `window` `keydown` listener for `Escape -> onClose`, calls `setPointerCapture`/`releasePointerCapture` during drag, and invokes `onDownload`/`onClose`.
- `[ReceiptPreview.tsx:ReceiptPreview]` None.
- `[ReceiptScanner.tsx:ReceiptScanner]` Triggers `cameraInputRef.current?.click()` on Take Photo click and invokes caller-supplied scan, camera capture, drag/drop, cancel, and file-picker click handlers.
