# Config

## Overview
Provides Spring Boot infrastructure configuration, HTTP security filter-chain wiring, CORS/Origin-Referer CSRF defenses, JCache/Caffeine cache management, bounded async thread pools, safe media-type/disposition helpers, startup database seeding, and global REST exception-to-JSON translation.

## Interface
- `[AsyncConfig.kt:AsyncConfig]` — `@Configuration` defining `@Bean(name = ["applicationTaskExecutor", "taskExecutor"]) fun applicationTaskExecutor(): ThreadPoolTaskExecutor` and `@Bean(name = ["ocrTaskExecutor"]) fun ocrTaskExecutor(): Executor`.
- `[CacheConfig.kt:CacheConfig]` — `@Configuration` defining `@Bean fun jCacheManager(): JCacheManager` and `@Bean fun cacheManager(jCacheManager: JCacheManager): CacheManager` for `"rate-limit-cache"` and `"storage-config-cache"`.
- `[DataInitializer.kt:DataInitializer]` — `@Component` implementing `CommandLineRunner` with `@Transactional override fun run(vararg args: String)` to seed default categories, app settings, and optional demo data (`seed.demo.users`).
- `[SafeMediaType.kt:SafeMediaType]` — Singleton `object` exposing `resolveSafeMimeType(fileName: String): String`, `isSafeInlineMime(mimeType: String): Boolean`, and `safeDisposition(fileName: String, mimeType: String, forceAttachment: Boolean = false): ContentDisposition`.
- `[SecurityConfig.kt:SecurityConfig]` — `@Configuration @EnableWebSecurity @EnableMethodSecurity` defining `passwordEncoder(): BCryptPasswordEncoder`, `filterChain(http: HttpSecurity): SecurityFilterChain`, `csrfOriginRefererFilter(): OncePerRequestFilter`, and `corsConfigurationSource(): CorsConfigurationSource`.
- `[ValidationExceptionHandler.kt:FxMarginsValidationException]` — `RuntimeException` subclass carrying `errors: Map<String, String>`.
- `[ValidationExceptionHandler.kt:ValidationExceptionHandler]` — `@RestControllerAdvice` handling `FxMarginsValidationException`, `AuthorizationDeniedException`, `MethodArgumentNotValidException`, `ConstraintViolationException`, `HttpMessageNotReadableException`, `MissingServletRequestParameterException`, `MethodArgumentTypeMismatchException`, `OptimisticLockingFailureException`, `DataIntegrityViolationException`, `MaxUploadSizeExceededException`, `MultipartException`, `MissingServletRequestPartException`, `HttpRequestMethodNotSupportedException`, `HttpMediaTypeNotSupportedException`, `ResponseStatusException`, `NoResourceFoundException`, and fallback `Exception`.

## Invariants
- `[AsyncConfig.kt:applicationTaskExecutor]` — `applicationTaskExecutor` / `taskExecutor` uses `corePoolSize=4`, `maxPoolSize=8`, `queueCapacity=100`, `threadNamePrefix="AppTask-"` (explicitly declared because `ocrTaskExecutor` suppresses Spring Boot's `@ConditionalOnMissingBean` `Executor` auto-configuration).
- `[AsyncConfig.kt:ocrTaskExecutor]` — `ocrTaskExecutor` uses `corePoolSize=2`, `maxPoolSize=5`, `queueCapacity=50`, `threadNamePrefix="OcrWorker-"`, and `ThreadPoolExecutor.AbortPolicy()` (rejects saturation with an exception rather than running on the caller thread).
- `[CacheConfig.kt:jCacheManager]` — Uses `CaffeineCachingProvider` with `storeByValue=false` and `CreatedExpiryPolicy`: `"rate-limit-cache"` expires in 1 hour and `"storage-config-cache"` expires in 5 minutes.
- `[DataInitializer.kt:run]` — Seeds 10 default `Category` rows only when `categoryRepository.count() == 0L`; seeds `AppSetting` keys `"mileage_rate_before_tax"` (`"0.60"`), `"mileage_rate_after_tax"` (`"0.40"`), and `"fx_margins"` only when `!appSettingRepository.existsById(...)`; seeds 4 demo `User` rows (`tech1`, `manager1`, `cfo1`, `mod1`) and sample `ExpenseReport`/`Expense` rows only when `seed.demo.users=true` and target tables are empty.
- `[SafeMediaType.kt:resolveSafeMimeType]` — Maps only lowercased extensions `{pdf, jpg, jpeg, png, gif, webp, doc, docx, xls, xlsx, txt, csv}` to explicit MIME types and falls back to `application/octet-stream` for all others.
- `[SafeMediaType.kt:safeDisposition]` — Emits `inline` `Content-Disposition` only when `!forceAttachment` and lowercased `mimeType` is in `{image/jpeg, image/png, image/gif, image/webp, application/pdf}`; otherwise forces `attachment` disposition with UTF-8 filename encoding.
- `[SecurityConfig.kt:filterChain]` — Enforces `SessionCreationPolicy.STATELESS` with CSRF disabled; permits unauthenticated access on `/api/auth/login`, `/api/auth/logout`, `/api/auth/refresh`, `/api/health`, `/error`, `/actuator/health`, `/actuator/info`, `/v3/api-docs/**`, `/swagger-ui/**`, `/swagger-ui.html`; requires `hasRole("mod")` on `/actuator/**`, `/api/settings/ocr/**`, `/api/settings/ldap/**`, `/api/settings/imap/**`, `POST /api/users`, `POST /api/categories`, `PATCH /api/categories/**`, `DELETE /api/categories/**`; requires `hasAnyRole("mod", "chef_finance")` on `/api/settings/fx-providers/**`; requires `authenticated()` on `/api/insurance/**` and `anyRequest()`; returns HTTP `401` `{"detail":"Unauthorized"}` JSON via `AuthenticationEntryPoint`.
- `[SecurityConfig.kt:csrfOriginRefererFilter]` — State-changing HTTP methods outside `{GET, HEAD, OPTIONS, TRACE}` on paths not starting with `{/api/auth/login, /api/auth/refresh, /api/health, /error, /actuator/health, /actuator/info}` must supply an `Origin` or `Referer` header whose extracted origin matches `cors.allowed-origins` (case-insensitive), or be rejected with HTTP `403`.
- `[SecurityConfig.kt:corsConfigurationSource]` — Applies CORS across `/**` with `cors.allowed-origins`, `allowCredentials=true`, methods `[GET, POST, PUT, PATCH, DELETE, OPTIONS]`, headers `[Authorization, Content-Type, Cookie, X-Requested-With, Accept, Idempotency-Key]`, and exposed header `[Set-Cookie]`.
- `[ValidationExceptionHandler.kt:ValidationExceptionHandler]` — Maps exceptions consistently to JSON `{"detail": ...}` responses (`400`, `403`, `404`, `405`, `409`, `413`, `415`, `ResponseStatusException.statusCode`, and `500`), adding `"errors"` map for `FxMarginsValidationException`.

## Side Effects
- `[AsyncConfig.kt:applicationTaskExecutor]` & `[AsyncConfig.kt:ocrTaskExecutor]` — Initialize Spring `ThreadPoolTaskExecutor` worker pools at application startup.
- `[CacheConfig.kt:jCacheManager]` — Creates JCache/Caffeine cache instances `"rate-limit-cache"` and `"storage-config-cache"` in memory if absent.
- `[DataInitializer.kt:run]` — Inserts initial `Category`, `AppSetting`, and (when `seed.demo.users=true`) demo `User`, `ExpenseReport`, and `Expense` records into PostgreSQL on startup.
- `[SecurityConfig.kt:filterChain]` & `[SecurityConfig.kt:csrfOriginRefererFilter]` — Registers `csrfOriginRefererFilter()`, `rateLimitingFilter`, and `jwtFilter` before `UsernamePasswordAuthenticationFilter`; writes HTTP `401`/`403` JSON error responses and logs Origin/Referer rejection warnings.
- `[ValidationExceptionHandler.kt:ValidationExceptionHandler]` — Emits SLF4J debug/warn/error logs on malformed payloads, optimistic-locking/data-integrity conflicts, multipart failures, and unhandled exceptions.
