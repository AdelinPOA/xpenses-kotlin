# GUI-Managed AI Providers and Model Chains

Moderators manage a shared AI provider/model catalog and independent model chains for receipt OCR and delegation-email parsing in the GUI. Providers may use HTTPS endpoints implementing the supported compatible multimodal API, but endpoints must resolve to public network addresses to prevent server-side request forgery and plaintext credential/image exposure; this boundary enables adding compatible providers and models without deployments, while avoiding a generic arbitrary-API configuration platform. The first model in each ordered chain is primary; any failure triggers the next model, and fallback stops at the first valid result. The application retains control of each workflow's prompt and result contract. New models must pass a synthetic end-to-end test before activation, provider credentials are encrypted, and deactivated models remain recognizable in historical configuration. Changes apply to subsequent processing calls while a running model-chain execution retains its initial configuration; durable job retries may read newer settings. Incompatible provider APIs require a backend integration.
