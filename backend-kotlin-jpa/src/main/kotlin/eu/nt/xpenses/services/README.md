# Backend Services

## Overview
Core business logic services in `eu.nt.xpenses.services` covering expense/report operations, OCR processing and recovery, delegation email ingestion, FX rate conversion, PDF/CSV/XLSX export, LDAP authentication/sync, encryption, authorization, idempotency, application settings, and file storage.

## Interface
- `[AppSettingsService.kt:AppSettingsService]` — manages daily allowance, mobile quick-add FAB flag, mileage rates, manual fuel prices (`getManualFuelPrice`), FX margins (`updateFxMargins` / `getFxMargins`), storage secret masking/restoration (`maskStorageSecrets`, `restoreStoredSecrets`), storage migration status, and orphan receipt scanning/cleanup
- `[AsyncOcrService.kt:AsyncOcrService]` — implements `[OcrJobPipeline.kt:OcrJobPipeline]` (`processOcr`, `recover`, `cancel`) for durable lease-backed async OCR, expense creation, and receipt promotion stages
- `[Authorization.kt:Authorization]` — RBAC/ABAC checks (`canView`, `canViewAll`, `canManage`, `canPay`, `canMutate`, `effectiveUserId`) across `ROLE_CHEF_FINANCE`, `ROLE_MANAGER`, `ROLE_MOD`, and `ROLE_TECHNICIAN`
- `[CryptoService.kt:CryptoService]` — HKDF-SHA256 key derivation (`getFernetKey`), AES-128-GCM encryption (`encrypt`), and AES-GCM (`0x81`) / legacy AES-CBC-HMAC (`0x80`) decryption (`decrypt`), validated via `validateSecrets`
- `[DelegationEmailText.kt:DelegationEmailText]` — internal Jsoup HTML-to-text normalizer (`normalize`) and order number extractor (`orderNumber`)
- `[DelegationParsingSettingsService.kt:DelegationParsingSettingsService]` / `[DelegationParsingSettingsService.kt:DelegationParsingConfig]` — reads/persists delegation AI prompt instructions, examples, and output instructions
- `[EmailImportService.kt:EmailImportService]` — parses delegation emails locally or via AI models (`parseDelegationEmailLocal`, `parseDelegationEmailWithModels`, `parseDelegationEmailAsync`), creates draft reports (`processIncomingEmail`, `createReportAndComplete`, `createReport`), simulates ingestion (`simulateIncomingEmail`), and handles user order previews/imports (`previewOrderForUser`, `importOrderForUser`)
- `[EmailSettingsService.kt:EmailSettingsService]` / `[EmailSettingsService.kt:EmailConfig]` / `[EmailSettingsService.kt:ImapConfig]` — manages encrypted SMTP/IMAP settings, tests connections, and sends `@Async` emails (`sendEmail`)
- `[ExpenseService.kt:ExpenseService]` / `[ExpenseVersionConflict.kt:ExpenseVersionConflict]` — CRUD, pagination/search (`listExpenses`, `getExpense`, `createExpense`, `updateExpense`, `duplicateExpense`, `deleteExpense`), idempotent optimistic-locked review (`reviewExpense`), receipt upload/download/deletion, and tabular export (`exportExpenses`)
- `[ExportService.kt:ExportService]` — generates CSV (`buildCsv`) and XLSX (`buildXlsx`) exports
- `[FxService.kt:FxService]` — resolves cached or provider FX rates with configured margins (`getRate`) and converts amounts to EUR (`convert`)
- `[IdempotentExpenseSaving.kt:IdempotentExpenseSaving]` / `[SaveIdempotencyService.kt:SaveIdempotencyService]` — coordinates idempotent expense creation, receipt manifest/file uploads, and bulk creation outside long DB transactions (`create`, `manifest`, `bindManifest`, `upload`, `lookupBulkCreate`, `bulkCreate`; `validateKey`, `hash`, `digest`, `lookup`, `execute`)
- `[LdapService.kt:LdapService]` / `[LdapService.kt:LdapConfig]` / `[LdapService.kt:LDAPUnavailableException]` / `[LdapService.kt:LDAPBindException]` — manages LDAP configuration, connection testing (`testConnection`), user sync (`syncUsers`), and bind authentication (`authenticateLdap`)
- `[OcrService.kt:OcrService]` / `[OcrService.kt:OCRProviderConfig]` / `[OcrService.kt:OCRModelConfig]` / `[OcrService.kt:OCRConfig]` — manages OCR provider/model catalog (`getOcrConfig`, `updateOcrConfig`, `saveOcrConfig`, `testModel`), receipt scanning with SHA-256 caching (`scanReceipt`), and fallback model chain execution (`runModelChain`, `scanModel`)
- `[OpenAiCompatibleClient.kt:OpenAiCompatibleClient]` — `DisposableBean` HTTPS client (`complete`, `validateBaseUrl`, `destroy`) with SSRF-blocking `PublicAddressDnsResolver` and `AiJsonSanitizer`
- `[OcrJobRecoveryScheduler.kt:OcrJobRecoveryScheduler]` — `@Scheduled` runner invoking `OcrJobPipeline.recover`
- `[OcrRecoveryService.kt:OcrRecoveryService]` — lists/fetches user OCR jobs (`listJobs`, `getJob`) and handles idempotent `retry` and `completeManually`
- `[OcrResultCacheCleanupService.kt:OcrResultCacheCleanupService]` — `@Scheduled` batched purge of expired `OcrResultCache` rows (`deleteExpiredEntries`)
- `[OcrSourceCleanupService.kt:OcrSourceCleanupService]` — `@Scheduled @Synchronized` bounded cleanup of expired terminal OCR source files (`cleanup`)
- `[PdfService.kt:PdfService]` — builds expense report PDFs with image receipts, signatures, and merged PDF receipts from precomputed `ReportTotals` (`generateReportPdf`)
- `[StorageService.kt:StorageService]` / `[StorageService.kt:StorageContext]` — manages active/remote storage providers, validates extensions/sizes/magic bytes (`validateMagicBytes`, `storeFile`), caches local copies (`getLocalPath`, `uploadFile`, `downloadFile`, `deleteFile`, `deleteOcrSource`), tests connections, and starts async migrations (`startMigration`)
- Child subpackages:
  - `fuel`: [./fuel/README.md](./fuel/README.md) - Multi-provider Romanian fuel price resolution, caching, and health monitoring (`FuelPriceProvider`, `FuelPriceService`, `FuelPriceHealthService`)
  - `fx`: [./fx/README.md](./fx/README.md) - Multi-provider HTTP/XML FX rate resolution (`FxRateProvider`, `HttpFxRateProvider`, `FxRateSource`)
  - `mapper`: [./mapper/README.md](./mapper/README.md) - Entity-to-DTO mapper (`ExpenseMapper`)
  - `storage`: [./storage/README.md](./storage/README.md) - Storage providers (`LocalStorageProvider`, `S3StorageProvider`), `StoragePathResolver`, and `StorageMigrationEngine`

## Invariants
- `[Authorization.kt:canManage]` / `[Authorization.kt:canPay]` / `[Authorization.kt:canMutate]` — `canManage` allows `chef_finance` and `manager` (not `mod`); `canPay` allows only `chef_finance`; `canMutate` requires `currentUser.id == ownerId`
- `[CryptoService.kt:validateSecrets]` / `[CryptoService.kt:decrypt]` — `encryption.secret` and `jwt.secret` must be non-blank and distinct; `decrypt` accepts only version `0x81` (AES-GCM, length >= 22) or `0x80` (AES-CBC + HMAC-SHA256, length >= 73)
- `[AppSettingsService.kt:updateFxMargins]` / `[FxService.kt:getRate]` — `RON` margin must be `0`; margins are `0..100` for `*` or `^[A-Z]{3}$` currency keys; `FxService.getRate` returns `BigDecimal.ONE` for `EUR` and requires `rate.signum() > 0`
- `[ExpenseService.kt:reviewExpense]` — requires authenticated exact owner, matching `requestHash` for reused `requestKey`, matching `expectedVersion` (else throws `ExpenseVersionConflict`), `verificationState == PENDING` with `lastVerifiedAt == null`, active linked `OcrJob`, non-empty receipts when `confirm == true`, `status == "draft"` when applying corrections, and consistent manual FX inputs
- `[ExpenseService.kt:doCreateExpense]` / `[ExpenseService.kt:updateExpense]` / `[ExpenseService.kt:deleteExpense]` — mutations require `canMutate`, `status == "draft"`, and active categories; cannot simultaneously set `categoryId` and `clearCategory`
- `[SaveIdempotencyService.kt:validateKey]` / `[SaveIdempotencyService.kt:checkHash]` / `[IdempotentExpenseSaving.kt:manifest]` — idempotency keys must match `^[A-Za-z0-9._:-]{1,256}$`; hash mismatches raise `409 Conflict`; files > 10 MB use `'oversize'` sentinel in manifests
- `[OpenAiCompatibleClient.kt:chatCompletionsEndpoint]` / `[OpenAiCompatibleClient.kt:PublicAddressDnsResolver]` — provider base URLs must use `https` without userInfo/query/fragment or internal/metadata hostnames, and DNS must resolve only to public IPs
- `[OcrService.kt:validateConfig]` / `[OcrService.kt:saveOcrConfigLocked]` / `[OcrService.kt:testModel]` — existing provider/model IDs cannot be removed; active models must be tested; modifying model/provider credentials invalidates `tested` and `active`; synthetic test requires `active == false`, finite amount near `12.34`, merchant containing `"test shop"`, date `"2025-01-15"`, and currency `"EUR"`; PDF rendering is capped at 5 pages
- `[AsyncOcrService.kt:processJob]` / `[OcrRecoveryService.kt:retry]` / `[OcrRecoveryService.kt:completeManually]` — jobs execute under 300s leases (`claimEligible`/`reclaimExpired`) with max 3 attempts (`30s * attemptCount` retry backoff; expired `PROCESSING` jobs at `attemptCount >= 3` are marked `PERMANENT_FAILURE` with `OCR_LEASE_EXPIRED`); recovery requires job ownership, valid unexpired source, and `PERMANENT_FAILURE` status
- `[OcrSourceCleanupService.kt:cleanup]` — `@Synchronized` bounded pass (batch 1..100) only deletes unshared `ocr-sources/` files on terminal expired jobs outside DB locks, transitioning `PERMANENT_FAILURE`/`UNRECOVERABLE` jobs to `EXPIRED`
- `[StorageService.kt:storeFile]` / `[StorageService.kt:deleteOcrSource]` — enforces `StorageContext` extension/size limits (`10 MB` for `OCR_SOURCE`/`RECEIPT`, `2 MB` for `SIGNATURE`; `50 MB` global cap in `uploadFile`), magic-byte validation (`validateMagicBytes`), masked-secret rejection, and non-symlink `ocr-sources/` path checks
- `[ExportService.kt:sanitizeFormula]` / `[LdapService.kt:syncUsers]` / `[PdfService.kt:buildMainPdf]` — CSV/XLSX strings starting with `=`, `+`, `-`, `@`, `\t`, `\r` are quote-prefixed; LDAP sync skips `authSource == "local"` users and runs searches outside DB transactions; PDF `totalReimbursable` excludes mileage (`totalEur + allowance - totalAdv`)
- `[EmailImportService.kt:parseOrderForUser]` / `[EmailImportService.kt:findActiveSender]` — automated email ingestion requires an active `technician` sender; manual order import requires active user, enabled OCR + non-empty `delegationModelChain`, and disallows fallback to local parsing

## Side Effects
- `[AppSettingsService.kt]` / `[DelegationParsingSettingsService.kt]` / `[EmailSettingsService.kt]` / `[LdapService.kt]` / `[OcrService.kt]` / `[StorageService.kt]` — read/write `app_settings` entries (`daily_allowance_rate`, `mobile_quick_add_fab_enabled`, `fx_margins`, `delegation_parsing_config`, `email_config`, `imap_config`, `ldap_config`, `ocr_config`, `storage_config`, `storage_migration_status`) with `CryptoService` encryption/decryption for secrets
- `[ExpenseService.kt]` / `[SaveIdempotencyService.kt]` / `[FxService.kt]` — read/write JPA entities (`expenses`, `receipts`, `expense_reports`, `fx_rates`, `ocr_comparisons`, `expense_save_requests`, `expense_review_operations`) and acquire PostgreSQL advisory (`pg_advisory_xact_lock`) or row locks (`SELECT ... FOR UPDATE`)
- `[AsyncOcrService.kt]` / `[OcrRecoveryService.kt]` / `[OcrJobRecoveryScheduler.kt]` / `[OcrResultCacheCleanupService.kt]` / `[OcrSourceCleanupService.kt]` — manage `ocr_jobs`, `ocr_job_action_operations`, and `ocr_result_cache` rows, dispatch `@Async("ocrTaskExecutor")` and `@Scheduled` jobs, and clean up storage objects
- `[OcrService.kt]` / `[OpenAiCompatibleClient.kt]` / `[EmailImportService.kt]` / `[EmailSettingsService.kt]` / `[LdapService.kt]` / `[FxService.kt]` — execute outbound HTTPS LLM requests, SMTP/IMAP network operations, LDAP/LDAPS directory binds/searches, and HTTP FX rate fetches
- `[StorageService.kt]` / `[AppSettingsService.kt:cleanOrphanReceipts]` / `[PdfService.kt]` — read/write/delete local filesystem and remote S3 objects via `StorageProvider`, execute async migrations via `StorageMigrationEngine`, and render/merge PDFs with OpenPDF and Apache PDFBox
