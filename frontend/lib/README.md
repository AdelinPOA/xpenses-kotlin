# Frontend Core Libraries (`frontend/lib`)

## Overview
Core client-side and SSR infrastructure for the Next.js frontend: authenticated Axios transport and single-flight token refresh, server-side SSR cookie-forwarding fetch, React Query keys and owner-scoped IndexedDB persistence, offline expense queuing/replay with cross-tab leasing, staged OCR receipt capture/recovery queues, locale-aware formatting, and navigation/form/scroll guards.

## Interface
- `./api/README.md`: Domain HTTP client wrappers (`admin.ts`, `delegationParsing.ts`, `expenses.ts`, `mileage.ts`, `reviewQueue.ts`) built on `api`.
- `./types/README.md`: Shared TypeScript domain interfaces, literal tuples, and type guards.

## Invariants
- `[api.ts:refreshSessionSingleFlight]` & `[api.ts:api.interceptors.response]`: Deduplicates refreshes via `refreshPromise` and Web Lock `"xpenses_auth_refresh"`; honors a 60s proactive cooldown (`xpenses_last_auth_refresh_at`); rejects immediately once `refreshRejected` is true (reset only by verified `/auth/login`, `/auth/me`, `/auth/refresh` responses); retries 401s at most once (`_retry`), never retrying `/auth/refresh` or `/auth/login`; dispatches `xpenses:terminal-auth-failure` only on terminal failure of `/auth/refresh` or retried `/auth/me`.
- `[authSession.ts:classifyAuthEndpointFailure]` & `[authSession.ts:cachesToPurgeOnLogout]`: Classifies `/auth/me` 401 and `/auth/refresh` 401|403 as `"terminal"`, network/408/425/429/>=500 as `"transient"`, and preserves `GENERIC_OFFLINE_SHELL_CACHE` (`"xpenses-v9"`) during logout cache purge.
- `[serverApi.ts:serverFetch]`: Aborts SSR prefetch when the `"access_token"` cookie is absent and throws on non-OK responses.
- `[queryPersister.ts:createQueryPersistence]`: Restores cached state only when active `ownerId` matches `payload.userId` and age `<= MAX_AGE_MS` (24h), serializing storage operations with generation fencing and purging IndexedDB on owner change or `setOwner(null)`; persists only `"success"` queries under root keys `"categories"`, `"expenses"`, `"reports"`, `"settings"`, `"dashboard"`.
- `[reviewQueueActions.ts:useReviewQueueActions]`: Rejects blank/whitespace-only rejection reasons before calling the API and trims submitted reasons.
- `[expenseSaving.ts:saveNewExpense]` & `[expenseSaving.ts:syncPendingExpenses]`: Enforces queue-first persistence before network calls; derives deterministic idempotency keys (`${id}:expense`, `${id}:receipts`); transitions `stage` from `"creation_pending"` to `"receipts_pending"` before receipt upload; renews lease every 10s via heartbeat while online/current; stops sync immediately on `"auth"` or network `"retryable"` errors.
- `[offlineQueue.ts:enqueueExpense]` & `[offlineQueue.ts:claimPendingExpense]`: Requires positive integer `userId`, enforces global queue caps (`MAX_QUEUE_SIZE = 20`, `MAX_QUEUE_BYTES = 100 MiB`), quarantines unowned/mismatched-owner records, enforces 30s `leaseToken`/`leaseUntil` concurrency checks (`OfflineQueueLeaseLostError`), and settles IndexedDB promises only on transaction `oncomplete`/`onerror`/`onabort`.
- `[ocrSourceQueue.ts:isValidUserId]`, `[ocrSourceQueue.ts:enqueueOcrSource]`, `[ocrSourceQueue.ts:claimOcrSource]`, `[ocrSourceQueue.ts:updateClaimedSource]`, `[ocrSourceQueue.ts:discardUnacceptedOcrSource]`: Requires positive integer `userId`, enforces `MAX_QUEUE_SIZE` (20) and `MAX_QUEUE_BYTES` (100 MiB), enforces 30s fenced leases (`LEASE_DURATION_MS = 30_000`) and monotonic `updatedAt`, forbids setting `uploadState` once `remoteJobId` is persisted or reassigning `remoteJobId`, and forbids local discard of accepted/active/uncertain entries.
- `[receiptCapture.ts:scanReceipt]` & `[receiptCapture.ts:interpretReceiptCapture]`: Validates `resumeJobId` and 202 `job_id` as positive safe integers; calls `onUploading` before `POST /ocr/scan` and `onAccepted` before polling `/ocr/status/{jobId}` (default `maxWaitMs = 5 * 60_000`); treats HTTP `[400, 401, 403, 404, 405, 413, 415, 422, 429]` as `definitelyRejected = true`; requires non-null `expense_id` and `receipt_id` to build `ReceiptCapture`.
- `[ocrRecovery.ts:requireJobId]` & `[ocrRecovery.ts:actionHeaders]`: Enforces positive safe integer `jobId` on `retryOcrJob`, `completeOcrJobManually`, and `getOcrJobStatus`, and requires a non-whitespace `idempotencyKey` for `retryOcrJob` and `completeOcrJobManually`.
- `[useBodyScrollLock.ts:useBodyScrollLock]`, `[useFormGuard.ts:useFormGuard]`, `[navigationGuard.tsx:useAllowNavigation]`: Reference-count body scroll locks (`lockCount`), push at most one `{ formGuard: true }` history entry per dirty lifecycle (permanently disarmed after `clearDirty()`), and short-circuit `useAllowNavigation` on the first `false` interceptor.
- `[fuelStatus.ts:useFuelPriceStatus]` & `[fxStatus.ts:useFxStatus]`: Configure React Query with `staleTime: 60_000`, `gcTime: 300_000`, `refetchInterval: 300_000`, `retry: false`, and execution gated by `enabled`; short-name formatters return `""` on nullish/empty input and fall back to the raw string if unmapped.
- `[mileageWeeks.ts:parseDateKey]`, `[mileageWeeks.ts:buildMileageWeeks]`, `[mileageWeeks.ts:shiftTripToDate]`, `[mileageWeeks.ts:buildPastePayload]`, `[mileageWeeks.ts:getWorkdayPasteTargets]`: Validate `YYYY-MM-DD` without calendar rollover, throw on invalid dates/non-positive trip durations, group into Monday–Sunday ISO weeks (default `maxSpanWeeks = 26`), omit `vehicle_id` when not in `validVehicleIds`, and skip weekends/duplicate trips (`origin`, `destination`, local `HH:mm`, `round_trip`) for Mon–Fri paste.

## Side Effects
- `[api.ts:api]`, `[auth.ts:login]`, `[serverApi.ts:serverFetch]`: Perform authenticated HTTP requests (`fetch`/`axios`), read/write `localStorage` (`xpenses_last_auth_refresh_at`), acquire Web Lock `"xpenses_auth_refresh"`, dispatch `xpenses:terminal-auth-failure`, navigate to `/login?next=...`, and trigger Web Share / blob anchor downloads (`URL.createObjectURL` + 60s revoke timer).
- `[queryPersister.ts:createQueryPersistence]`: Reads, writes, and deletes `"persisted_state"` in IndexedDB `"xpenses-cache"` (`"react_query"` store) on a 1s debounce and subscribes to `queryClient.getQueryCache()`.
- `[offlineQueue.ts:openDb]` & `[expenseSaving.ts:withLeaseHeartbeat]`: Opens/upgrades IndexedDB `"xpenses-offline"` (v2, `"pending_expenses"` store), generates UUIDs via `crypto.randomUUID()`, registers 10s `setInterval` lease heartbeats, and executes `POST /expenses` and `POST /expenses/${expenseId}/receipts`.
- `[ocrSourceQueue.ts:openDb]`, `[receiptCapture.ts:scanReceipt]`, `[ocrRecovery.ts:retryOcrJob]`: Opens/upgrades IndexedDB `"xpenses-ocr-sources"` (v2, `"pending_sources"` store), generates UUIDs via `crypto.randomUUID()`, compresses images via `FileReader` + `Image` + `<canvas>`, runs a 1000ms progress interval and 1500ms polling delays, and calls `POST /ocr/scan`, `GET /ocr/status/{jobId}`, `GET /ocr/jobs`, `POST /ocr/jobs/{jobId}/retry`, and `POST /ocr/jobs/{jobId}/complete-manually`.
- `[reviewQueueActions.ts:useReviewQueueActions]`: Submits report approve/reject API mutations and invalidates TanStack Query caches.
- `[format.ts:setCurrentLocale]`, `[haptics.ts:triggerHaptic]`, `[useBodyScrollLock.ts:useBodyScrollLock]`, `[useFormGuard.ts:useFormGuard]`, `[navigationGuard.tsx:useRegisterNavigationGuard]`: Mutate module-level locale/formatter caches, call `navigator.vibrate`, mutate `document.body.style.overflow`, push `window.history` state, register `popstate`/`beforeunload` listeners, and invoke `window.confirm`.
- `[fuelStatus.ts:useFuelPriceStatus]` & `[fxStatus.ts:useFxStatus]`: Execute React Query async fetching (`getFuelPriceStatus`, `getFxStatus`) when `enabled` is `true` and poll every 5 minutes.
- `[mileageWeeks.ts:buildMileageWeeks]`: Reads system clock via `new Date()` only when `includeEmptyDays` is `true`, `weekStarts` is empty, and `fallbackTodayKey` is omitted/invalid.
