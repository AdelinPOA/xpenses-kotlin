## Milestone Summary

**Key Decisions:**
- Decision: Use exact BigDecimal arithmetic and NUMERIC PostgreSQL column types for all financial quantities.
- Decision: Preserve frozen historical rates on existing records; migrations never silently mutate posted values.
- Decision: Fallback to dated Frankfurter ECB endpoint when BNR lacks requested currency.
- Decision: Provide null-safe handling and canonical mapping for FX margin settings in frontend.

**Issues Resolved:**
- Closed verification gaps for mileage EUR identity rate resolution.
- Fixed frontend SettingsClient crash on incomplete mock/missing properties.
- Added comprehensive Testcontainers PostgreSQL migration regression suite.

**Technical Debt Incurred:**
- None in the FX domain.
